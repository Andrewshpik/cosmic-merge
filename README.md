# Cosmic Merge

Браузерная физика-merge игра в стиле Suika Game / Watermelon Game, но в космической стилистике: бросаешь пыль → молекулы → атомы → астероиды → планеты → звёзды → пульсары → галактики.

**Стек:** Matter.js (физика) + Canvas2D (рендер) + Web Audio API (звук). Один HTML, один CSS, один JS — без сборщика.

## Запуск

Двойной клик на `index.html`. Для CDN с Matter.js нужен интернет (~100 KB).

## Управление

| Действие | Десктоп | Мобильный |
|----------|---------|-----------|
| Прицеливание | Мышь | Палец |
| Бросить | Клик / Space | Тап |
| Заново | ↻ кнопка / R | ↻ кнопка |

## Правила

- Бросаешь сферу с верха в свободное место
- Две сферы **одинакового тира при касании сливаются** в следующий тир
- Очки = (тир + 1) × 10 за каждое слияние
- **Game Over** если сфера остановилась выше красной пунктирной линии дольше 1.5 секунд
- Цель — собрать **Галактику** (11-й тир)
- Лучший счёт сохраняется в localStorage

## Структура

```
index.html        ← разметка, подключает Matter.js c CDN
style.css         ← стили (тёмная космо-тема)
js/game.js        ← вся игровая логика
```
